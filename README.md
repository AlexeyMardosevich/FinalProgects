<small>Учебный проект Java-разработки</small>

Учебное веб-приложение интернет-магазина книг на Spring Boot. 
Проект демонстрирует работу с MVC, JSP, REST API, Spring Data JPA, PostgreSQL, Spring Security, корзиной заказов и модульными тестами.

## Возможности

- Просмотр списка книг.
- Просмотр информации о конкретной книге.
- Создание, редактирование и удаление книг.
- Регистрация и управление пользователями.
- Аутентификация пользователей.
- Разграничение доступа по ролям.
- Добавление книг в корзину.
- Изменение количества товаров в корзине.
- Удаление товаров из корзины.
- Оформление заказа.
- Изменение статуса заказа.
- Постраничный вывод данных через `Pageable`.
- REST API для работы с книгами и пользователями.
- Валидация DTO.
- Централизованная обработка ошибок REST API.
- Локализация JSP-страниц.
- JUnit и Mockito тесты.

## Технологии

- Java 17.
- Spring Boot 2.7.14.
- Spring MVC.
- Spring Data JPA.
- Hibernate.
- Spring Security 5.7.
- PostgreSQL.
- JSP и JSTL.
- Apache Tomcat.
- Maven.
- Lombok.
- JUnit 5.
- Mockito.
- MockMvc.
